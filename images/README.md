# Твой рисунок

Без файлов игра покажет встроенного лиса. Чтобы заменить его, положи сюда
свой PNG с именем **pet.png** и перезапусти программу. Подойдёт изображение
256 × 256 или 512 × 512 пикселей; прозрачный фон предпочтителен. Оболочка
впишет рисунок в экран, сохраняя пропорции.

По желанию добавь изображения того же персонажа с такими именами:

- `happy.png` — настроение от 7;
- `hungry.png` — голод от 8;
- `tired.png` — энергия не больше 2;
- `sleeping.png` — короткая реакция на сон.

При совпадении условий приоритет: сон сразу после действия → усталость →
голод → радость → обычное состояние. Отсутствующее состояние заменяется
`pet.png`, а если его тоже нет — встроенным рисунком.

Рисунки загружаются при запуске. Можно нарисовать их в Paint и сохранить
как PNG. Простое переименование JPG в PNG не меняет формат изображения.
